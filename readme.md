# 🧮 Reprice Bot WB

Telegram-бот для автоматического расчёта **«Черной цены»** продавца на Wildberries. Фактически ручной репрайсер, упрощающий расчет цен "до рубля". Сокращает время обновления всех цен на 50% (личный опыт, субъективное мнение, не исключает ручную работу - но делает ее значительно проще). В среднем, 400 товаров получалось обновить за 120 минут, необходимость повторения операции - ориентировочно раз в неделю. Не забывайте выходить из всех акций ;)

Принимает файл `.xlsx` или `.xls`, вычисляет новую цену до скидки так, чтобы итоговая цена для покупателя стала равна желаемой, и возвращает заполненный файл который необходимо загрузить на странице обновления цен. Если цена не соответствует минимально установленной - в колонку "Новая цена" устанавливается минимальная цена "До скидки". 
Для работы с ботом пользователю необходимо скачать стандартный файл обновления цен с сайта ВБ в разделе "Цены и скидки", добавить в него сбоку три колонки: "текущая_конечная_цена", "желаемая_конечная_цена", "цена мин". Колонка "текущая_конечная_цена" - ручной труд менеджера, заполняется в соответствии с "черной" ценой с сайта перед расчетом. Колонки "желаемая_конечная_цена", "цена мин" заполняются единожды по всем товарам. "желаемая_конечная_цена" - черная цена которую вы хотите видеть у покупателя, "цена мин" - минимальная цена "до скидки", ниже которой бот не опустит цену - сделано для того, чтобы выдержать маржинальность вне зависимости от СПП, потому что СПП может резко падать что приведет к продаже в минус. Этот механизм защищает от чрезмерного занижения цены.

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install aiogram openpyxl pandas xlrd
```

### 2. Настройка токена

Создай файл `.env` в корне проекта:

```
TELEGRAM_BOT_TOKEN=your_token_here
```

### 3. Запуск

```bash
python -m app.main
```

---

## Как пользоваться

1. Запусти бота командой `/start`
2. Отправь файл `.xlsx` или `.xls` **как документ** (не как фото) Предварительно заполненный текущими ценами по каждому товару.
3. Бот заполнит колонку **«Новая цена»** и вернёт файл

## Формула расчёта

Бот находит такую новую цену продавца `P_new`, при которой конечная цена для покупателя будет равна желаемой.

```
factor    = 1 - скидка% / 100
P_after   = P_before × factor
k         = P_current / P_after
P_new     = P_target / (k × factor)
```

Если `P_new` оказывается ниже `цена_мин` — ставится минимальная цена.

Результат всегда округляется вверх до целого.

## Формат входного файла

Бот **автоматически** определяет строку заголовков (сканирует первые 50 строк) и распознаёт колонки по синонимам — строгое совпадение названий не требуется.

### Обязательные колонки

| Колонка | Примеры названий |
|---|---|
| Текущая цена продавца | `Текущая цена`, `Цена`, `Цена до скидки` |
| Текущая скидка | `Текущая скидка`, `Скидка`, `Скидка %` |
| Текущая конечная цена | `Текущая конечная цена`, `Конечная цена`, `К оплате` |
| Желаемая конечная цена | `Желаемая конечная цена`, `Целевая цена`, `Target price` |
| Минимальная цена | `цена_мин`, `Минимальная цена`, `Мин цена` |

### Выходная колонка

Бот добавит или заполнит колонку **`Новая цена`**. Если такая колонка уже есть — перезапишет её.

## Структура проекта

```
bot/
├── main.py       — точка входа, запуск бота
├── handlers.py   — Telegram-хендлеры
├── reprice.py    — формула, поиск колонок, обработка файлов
├── parsers.py    — нормализация строк и парсинг чисел
├── state.py      — хранение состояния пользователей
└── config.py     — загрузка .env и токена
```

## Кнопки «Сброс» и «Пересчитать Новая цена»

> ⚠️ **Эти кнопки не несут практической функции в текущей версии** — бот работает только в одном режиме (`REPRICE`), поэтому переключать нечего.
>
> Они добавлены **намеренно как точка расширения**: если ты захочешь добавить новые режимы обработки (например, аналитику, прогнозирование цен, другие формулы), архитектура уже готова — достаточно:
>
> 1. Добавить новый `Mode` в `state.py`
> 2. Написать логику обработки в отдельном модуле
> 3. Добавить кнопку и хендлер в `handlers.py`
>
> Менять остальной код при этом не нужно.
